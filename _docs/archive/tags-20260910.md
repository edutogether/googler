## 2단계 실행 기록 (2026-09-10)

- 12개 태그를 `refs/archive/tags/<이름>`으로 옮김 — **삭제가 아니라 이동**:
  먼저 `refs/archive/tags/<이름>`을 원본과 같은 커밋(정확히는 같은 **태그
  오브젝트** — 최초 시도에서 실수로 커밋 SHA로 만들어 태그 메시지가 빠질
  뻔한 것을 바로 발견해 태그 오브젝트 SHA로 다시 만들었다)으로 만들어
  push한 뒤에 원본 `refs/tags/<이름>`을 삭제했다.
- `.githooks/pre-push`가 `*-freeze-*` 이름의 원격 태그 삭제를 막아서,
  **원격 삭제 12건 전부 `git push --no-verify`로 우회했다**(팀장 명시 승인,
  이번 1회 한정).
- 로컬 `git tag`, 원격 `git ls-remote --tags`가 둘 다 남기는 2개만 보이는
  것 확인.
- `git checkout refs/archive/tags/googler-freeze-20260902 -- .`를 실제로
  실행해 옮긴 태그가 정말 되돌아가는지 확인 — 원위치 과정에서
  `git checkout HEAD -- .`만으로는 옛 커밋에만 있던 파일(`docs/` 3개)이
