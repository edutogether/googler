## 꺼내는 법 — 새로 클론한 곳에서는 이 두 줄이 반드시 필요하다

**`refs/archive/*`는 `git clone`·`git fetch`가 기본으로 가져오지 않는다.**
이 저장소의 기본 fetch refspec은 `+refs/heads/*:refs/remotes/origin/*`뿐이라,
새로 클론한 곳에서 그냥 `git checkout refs/archive/tags/<이름>`을 치면
"그런 게 없다"고 나온다. 먼저 그 네임스페이스를 명시적으로 받아와야 한다:

```bash
git fetch origin 'refs/archive/*:refs/archive/*'
git checkout refs/archive/tags/<이름>
```

이 두 줄이 없으면 "커밋은 그대로 살아 있다"가 새로 이 저장소를 여는
사람에게는 사실상 거짓이 된다(COMMON_STANDARDS §23-6, Poster Studio가
찾은 구멍).
