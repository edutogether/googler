# Be a Googler

같이교육 구성원이 Google Educator Level 1·2부터 Google Certified Trainer와 Innovator까지 단계적으로 학습하고, 진도와 성장을 함께 관리하는 웹앱입니다.

## 주요 기능

- Google Educator Level 1·2 학습 로드맵
- 학습자료 및 실습 링크 제공
- 일자별 학습 체크리스트
- 개인 진도율 확인
- 구성원 학습 랭킹
- 시험 응시 및 합격 기록

## 개발 예정 기능

- 이름과 PIN 기반 로그인
- 일반 사용자·관리자·슈퍼어드민 권한
- 개인 공부 캘린더 및 학습 다이어리
- 주간 학습 리포트
- 배지와 연속 학습 기록
- Trainer·Innovator 준비 과정
- Firebase 기반 사용자·진도 데이터 관리

## 기술 구성

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase
- GitHub Pages
